# 07-modulo-n

Read N, then N integers on the next line. Apply modulo from left to right.

1 ≤ N ≤ 100000.
Integers: 0 ≤ first ≤ 10^9; 1 ≤ remaining values ≤ 10^9.
Time limit: 4 seconds per test.

`a % b` gives the remainder. Example: `17 % 5 = 2`.

Compute `((a1 % a2) % a3) ...`. For N = 1, print a1.

Example Input:
```text
3
100 30 7
```

Example Output:
```text
3
```
