# 08-product-two

Read two integers. Print their product modulo 1000000007.

Integers: 0 to 10^9.
Time limit: 4 seconds per test.

Use `long` for arithmetic (`scanner.nextLong()`).

Use `% 1000000007` after every multiplication.

```java
long answer = (a * b) % 1000000007L;
```

Example Input:
```text
1000000000 2
```

Example Output:
```text
999999993
```
