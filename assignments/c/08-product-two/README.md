# 08-product-two

Read two integers. Print their product modulo 1000000007.

Integers: 0 to 10^9.
Time limit: 2 seconds per test.

Use `long long` for arithmetic (`%lld` with scanf/printf).

Use `% 1000000007` after every multiplication.

```c
long long answer = (a * b) % 1000000007LL;
```

Example Input:
```text
1000000000 2
```

Example Output:
```text
999999993
```
